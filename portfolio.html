Projects

Bioinformatics Research Toolkit

August 2026 - Present

For the past few months I've been working in Dr. Benjamin Neuman's Lab at Texas A&M University, under the PiCoRNA Project. I've been developing a web-based research tool for undergraduate researchers to use when working with biological sequence data.

I collaborated on the creation of a Flask application that allows researchers to submit nucleotide sequences, compare them with NCBI BLAST+, and store sequence data in PostgreSQL. I containerized the application using Docker, separating the Flask server and PostgreSQL database into independent services deployed on the lab's Mac Mini for students to access.

More recently, I've been developing a Python tool that will help students retrieve information from NCBI GenBank records and automatically generate Word documents in the lab's required format.

Restaurant POS System

September 2026 - October 2026

For a software engineering course at Texas A&M, I worked on a restaurant point-of-sale system built using JavaFX and PostgreSQL.

I was primarily responsible for the backend of the project, which handled orders, database interactions, and kept track of inventory. One of the more interesting challenges of this project was making sure that orders, pricing, and inventory updates were handled consistently and meaningfully, especially whenever something goes wrong with a database transaction.

This project gave me a better understanding of how features work together in larger applications, and how important it is to design backend systems that are reliable and easy to manage.

LLM Routing System

June 2026 - August 2026

During my internship at EPAM Systems, I developed an intelligent routing system that selects between language models to balance response quality, inference cost, and latency.

One of the most interesting parts of this project was learning that selecting the best model is not simply a matter of choosing the most capable one. While larger models may provide a stronger response, they also introduce unnecessary cost and latency into the equation. Because of this, the routing system that I built attempted to balance quality against cost and latency when deciding which model should handle a request.

While developing the system, I experimented with semantic caching, prompt classification, and DeBERTa-based models while also working with FastAPI, Docker, SQLite, and Streamlit. Being able to work with all of these technologies together was extremely valuable to me, as it gave me experience thinking about machine learning systems as a whole, rather than just thinking in terms of model performance.

S.H.A.D.E.

August 2025 - December 2025

S.H.A.D.E. was a machine learning research project focused on predicting heat index and finding days with elevated heat risk using Austin's historical environmental data.

In this project, I built LSTM models with TensorFlow and Keras using 25 years of environmental data from Austin, Texas. Working with this data gave me hands-on experience preparing data inputs, tuning machine learning models, and evaluating them.

After we had tuned the models, they achieved an R2 of 0.80 for temperature forecasting and 90.6% test accuracy for heat-risk classification. More importantly, however, this project taught me how important decisions made during the data pre-processing phase are, as they can heavily affect the performance of machine learning models.

Having spent an absurd amount of time playing VALORANT, I figured I'd combine my interest in programming with my interest in messing with my friends.
